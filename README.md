# Zane's Karate Journey — original PDF layout
This static website renders all six original Canva PDF pages in the same order and visual layout, with responsive scaling and navigation.

## Asset upload required
Upload these files to the repository alongside the existing HTML, CSS and Vercel configuration:
- `assets/page-1.png` through `assets/page-6.png`
- `Zane-Karate-Original.pdf`

These images and the PDF are supplied in the website ZIP in the ChatGPT conversation. Do not deploy until they are added; the HTML references them directly.

## Deploy to Vercel
Use Vercel **Add New → Project**, import `plusultratablet1-tech/Zane-Karate` into your `Bearfitph's projects` team, set Framework Preset to **Other** (static HTML), and deploy. No environment variables are needed.

## Notes
This is a visual reproduction, not editable HTML text. Content, including any duplicate historical pages and old tournament details, remains exactly as in the uploaded PDF.
